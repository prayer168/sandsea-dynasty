# 沙海王朝 Sandsea Dynasty

在瀏覽器裡玩的 3D 即時戰略遊戲。三大家族爭奪沙海星球上的香晶：採集資源、建造基地、發展科技，同時提防沙海深處的巨蟲。

整個遊戲就是一個 `index.html`，下載後用瀏覽器開啟即可遊玩，不需要安裝或建置。首次載入需要連上網路，以取得 three.js 與字型。

## 內容

- **三個家族**：蒼隼、鐵砧、幻蛇
- **戰役**：七道任務依序解鎖，目標分為香晶配額、堅守、殲滅三種，科技逐關開放
- **自由對戰**：全科技開放的單局對戰
- **三種難度**：簡單、普通、困難
- **自動存檔**：任務成績與最佳用時保存在瀏覽器中

## 操作

| 功能 | 按鍵 |
| --- | --- |
| 選取 | 左鍵點選、拖曳框選；Shift 加選 |
| 指令 | 選取單位後點地面移動、點敵人攻擊；右鍵亦可下指令 |
| 採集 | 採晶車點香晶田採集、點煉晶廠返回卸貨 |
| 建造 | 點指揮中樞 → 選建築 → 完工後點「放置」再點岩地 |
| 鏡頭 | WASD／方向鍵、滑鼠推邊、中鍵拖曳、滾輪縮放、Q/E 旋轉、H 回基地 |
| 編隊 | Ctrl＋1～9 編組、數字鍵選取（連按兩次跳至該隊） |
| 其他 | X 停止、` 全選戰鬥單位、P 暫停、Esc 取消 |
| 觸控 | 單指點選與拖曳平移、雙指縮放；「框選」按鈕切換框選 |

## 技術

單一 HTML 檔，使用原生 JavaScript 與 [three.js](https://threejs.org/) 0.160.0（由 CDN 載入）。模型、地形與音效都由程式即時產生，沒有外部素材檔。
